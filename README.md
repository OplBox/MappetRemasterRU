# Сборка MappetRemasterRU с помощью Google Colab

**ВАЖНО: Используйте только ноутбук `Build.ipynb`**

## Инструкции

1.  **Закройте все старые вкладки с ноутбуками Colab, которые вы использовали ранее.**
2.  **Нажмите на эту ссылку, чтобы сразу открыть правильный ноутбук в Google Colab:**
    [![Открыть в Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/OplBox/MappetRemasterRU/blob/main/Build.ipynb)
3.  Выполняйте ячейки последовательно, нажимая `Shift+Enter`.
4.  Дождитесь завершения сборки.
5.  Скачайте собранные файлы из файлового менеджера слева в интерфейсе Google Colab.
