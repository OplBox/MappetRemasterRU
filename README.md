# Сборка MappetRemasterRU с помощью Google Colab

Этот репозиторий содержит ноутбук Google Colab, который поможет вам собрать проект MappetRemasterRU и его документацию.

[![Открыть в Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/OplBox/MappetRemasterRU/blob/main/MappetRemasterRU_Build_Easy.ipynb)

## Инструкции

1.  Нажмите на кнопку "Открыть в Colab" выше, чтобы открыть ноутбук в Google Colab.
2.  В первой кодовой ячейке вы увидите поле `repository_url`. Вставьте туда ссылку на ваш GitHub репозиторий, если он отличается от `https://github.com/OplBox/MappetRemasterRU.git`.
3.  Выполняйте ячейки последовательно, нажимая `Shift+Enter` в каждой ячейке.
4.  Дождитесь завершения сборки. Это может занять несколько минут.
5.  После завершения сборки вы найдете собранные файлы в директориях, указанных в последней ячейке ноутбука. Вы можете скачать их из файлового менеджера слева в интерфейсе Google Colab.
